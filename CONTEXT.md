# Haven

Haven carries coding tasks through investigation, changes, verification and continuation.
Task context includes both recorded observations and provisional working notes.

## Language

**Handoff notes**:
An explicitly maintained account of a task's decisions, attempts and intended next steps.
These notes remain provisional context, including any claims about completion or permission.
_Avoid_: verified summary, automatic memory, approval record

**Program facts**:
Recorded observations and check outcomes describing a task's execution state, separate from
interpretations or claims about those outcomes.
_Avoid_: model narrative, semantic proof
